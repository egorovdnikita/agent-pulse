# Pulse — паспорт проекта (рабочее название)

> Репозиторий исторически называется Agent Pulse. Решения владельца, отличающиеся от исходного паспорта, отмечены **[решение]**.

## Что это

Pulse = маскот + Пульт. Маскот — характер, Пульт — инструменты. Пульт — единственное место, где есть ввод, команды и голос. Маскот их не получает никогда.

Маскот — живой характер ноутбука. Маленький светящийся круг с двумя глазами живёт поверх всех окон на всех рабочих столах и показывает, как себя чувствует Mac и что делают ИИ-агенты. Говорит короткими репликами в облачке, реагирует на тебя, на время суток и на состояние железа, иногда шутит.

Это не инструмент. У него нет поля ввода, команд, голоса, настроек на десять экранов. Он ничего не делает за тебя — он присутствует. Ценность в двух вещах:

1. **Ноутбук становится понятным без чтения.** Батарея, перегрев, сеть, агент ждёт или закончил — считывается краем глаза по взгляду и свечению.
2. **Ноутбук становится живым.** Человечные реакции, ритуалы, редкие приколы. Ощущение, что рядом кто-то есть.

## Принципы характера

Каждое решение по продукту проверяется этими правилами. Если фича им противоречит — фича не делается.

Принципы «Присутствие, не функционал» и «Знает, как чувствует себя ноутбук…» относятся к маскоту. Для Пульта свой принцип: **видит только то, что ты дал явно** — нажал клавишу, бросил файл, включил модуль.

- **Присутствие, не функционал.** Никаких полей ввода, голосового управления, запуска команд, кнопок действий. Единственные действия пользователя — смотреть, гладить, тыкать, перетаскивать и кликнуть, чтобы перейти к источнику события.
- **Редкость = человечность.** Шутка, повторённая трижды за день, становится багом. У приколов есть дневной бюджет.
- **Важное никогда не тонет в милом.** Агент ждёт тебя — это всегда громче любой шутки.
- **Без чувства вины.** Он не умирает, не голодает всерьёз, не упрекает, не требует внимания. Тамагочи наоборот: заботится он, а не ты.
- **Знает, как чувствует себя ноутбук, но не знает, что ты в нём делаешь.** Только системные сигналы. Никакого чтения окон, буфера, файлов, названий приложений и сайтов.
- **Тишина уважается.** Созвон, режим фокуса, полный экран, презентация — эмоции только глазами, облачко молчит.

## Позиционирование

Утилиты уведомлений для агентов и десктоп-питомцы существуют по отдельности. Pulse — это одно существо, у которого агенты являются одним из органов чувств наравне с батареей и временем суток. Дифференциация — в качестве характера: минималистичная пластика, мягкий язык, память о дне и строгий бюджет на внимание.

Целевые ресурсы: CPU в покое ~0%, RAM < 60 MB с выключенным Пультом, < 70 MB с включённым, в `sleep` рендер ≤ 15 fps, при скрытой панели — 0 кадров и мозг раз в секунду. Локальный порт плагина Figma отвечает только запросам без `Origin` или с `Origin: null` (песочница плагина) — сайт в браузере событие не подделает.

Позиция по умолчанию **[решение]**: правый нижний угол дисплея с Dock, на уровне Dock. В полноэкранном режиме (видео, презентация, игра) маскота не видно **[решение]**: панель без `fullScreenAuxiliary`, и вдобавок раз в 0.5 s и при смене рабочего стола проверяется, нет ли на экране маскота окна размером с весь экран у приложения, с которым ты сейчас работаешь (только слой, размеры и pid окон, без названий), и строка меню на этом экране скрыта (на обычном рабочем столе она видна всегда), — если так две проверки подряд (~1 s, чтобы не путать с переходом между рабочими столами), панель убирается; панель, показанная во время перехода между столами, может прилипнуть к одному столу — поэтому при каждом показе она заново объявляет себя окном «на всех столах», а после смены стола, если её тут нет (и это не полноэкранный стол), возвращается сама (`panel rejoin` в журнале): окно убирается и выкладывается заново, а если и это не помогло — панель пересоздаётся (`panel rebuild`; `--rebuild-panel` — проверить вручную). Одного переобъявления мало: после полноэкранного Chrome оно срабатывало 12 раз подряд впустую; каждое «спрятался/появился» с причиной пишется в системный журнал (`log show --predicate 'subsystem == "io.github.egorovdnikita.agentpulse"'`); пока её не видно, кадры не рисуются.

### Контракты

```swift
protocol Sense: Sendable {
  var id: SenseID { get }
  func start(emit: @escaping @Sendable (Signal) -> Void)
  func stop()
}

struct Signal: Sendable {
  let sense: SenseID
  let kind: SignalKind          // .batteryLow, .charging, .thermalHigh, .agentAwaitingUser, ...
  let value: Double?            // уровень, если есть
  let ts: Date
}

enum Tier: Int, Comparable {    // порядок = приоритет
  case agent = 0, body, rhythm, interaction, fun
}

struct ReactionSpec {
  let id: ReactionID
  let trigger: SignalMatcher
  let tier: Tier
  let cooldown: Duration
  let dailyLimit: Int?
  let moodGate: MoodPredicate?  // например, «не шутить, если stress > 0.7»
  let behavior: BehaviorID
  let phrases: PhrasePoolID?    // nil = реакция только глазами
  let bubbleDuration: Duration
}
```

Добавить реакцию = одна запись в `ReactionCatalog` + пул реплик + поведение (если нового нет). Ядро не трогается. `Director` — единственное место, где принимается решение «реагировать ли сейчас».

### Мозг: настроение

Четыре оси, каждая 0…1, плавно затухают к нейтрали (период полураспада ~30 мин):

| Ось | Растёт от | Падает от |
|---|---|---|
| `energy` | утро, зарядка, пробуждение | ночь, батарея < 20%, uptime > 7 дней, долгая работа |
| `stress` | перегрев, нехватка памяти, ошибки агентов, мало места | покой, успешные задачи |
| `joy` | поглаживание, завершённые задачи, пятница, праздники | тычки, серия ошибок |
| `social` | взаимодействие, твоё присутствие | долгое отсутствие |

Настроение не порождает реплики само по себе — оно окрашивает всё: `Baseline` задаёт частоту моргания, скорость саккад, размер глаз, яркость свечения; `PhrasePicker` выбирает вариант реплики под настроение; `moodGate` отключает шутки в стрессе.

Осанка по времени суток (`Baseline`): утром моргает чаще и движется живее, 14–16 — лёгкий спад, поздно вечером тело оседает и движения тяжелеют. Довольный (`joy` > 0.65) изредка подпрыгивает на месте, уставший оседает.

### Мозг: знакомство

`familiarity` 0…1 из памяти: дни рядом (две недели — 0.7) и поглаживания. Чем лучше знакомы, тем смелее: незнакомому — половина бюджета приколов, знакомому — тёплое «Привет-привет».

### Мозг: память

Хранится локально, только агрегаты, никаких содержимых:

- День: сколько задач агентов, ошибок, перерывов, сколько раз гладили и тыкали, время первого и последнего присутствия.
- Привычки: медианное время начала и конца дня за 14 дней, обычные дни недели.
- Используется для: «Рано ты» (начал на 2 ч раньше медианы), «Тяжёлый день» вечером после многих ошибок, «Неделя ок» в пятницу, мягкий тон вечером после трудного дня.
- Хранение 30 дней, затем удаляется. Сброс одной кнопкой.

### Director: бюджет и приоритеты

| Уровень | Примеры | Ограничение |
|---|---|---|
| `agent` | ждёт тебя, готово, ошибка | без лимита; `wait_you` вытесняет всё |
| `body` | батарея, перегрев, сеть, мониторы | кулдаун на сигнал 30 мин, гистерезис порогов |
| `rhythm` | приветствие, поздно, пятница, перерыв | каждая реакция ≤ 1 раза в день |
| `interaction` | гладить, тыкать, бросать | всегда, это ответ на действие пользователя |
| `fun` | чих, икота, муха, прятки | до 8 в день **[решение]**, ≥ 25 мин между, только при `stress < 0.5` и присутствии пользователя |

Общие правила:
- Облачко одно за раз; реакции встают в очередь по приоритету.
- Наложения **[решение]** (`BubbleScheduler`): ожидание тебя вытесняет всё фоновое (тело, ритм, новости, приколы — облачко пропадает, тело реагирует глазами); ответ на твоё действие (`answersUser`: кабель, тычок, поглаживание) вклинивается в ожидание на время чтения, затем возвращается то же облачко ожидания; ответил агенту, пока висит ответ, — ожидание не возвращается. Облачко ожидания не висит вечно **[решение]**: ты 8 s за компьютером при нём (был ввод) — значит, видел, облачко сворачивается; увиденное ожидание уступает **[решение]**: работает другой агент — маскот в его работе, иначе обычный покой (сон — через обычную паузу от момента, когда увидел); сессия по-прежнему ждёт в меню, а наведение первым показывает «Жду тебя уже N мин»; «Эй…» через 5 мин — только для невиденного ожидания; новое ожидание той же сессии снова смотрит на тебя (`MascotStateMapper.demotingSeen`). Каждая смена состояния пишется в журнал с фазами сессий (`state … → … [codex:working,…]`), без текста. Агентное встаёт в очереди впереди тела и ритма. Одно физическое событие — одна реплика: подключил уже полный — «Ммм…», без «Сыто» вдогонку. «Вынули без извлечения» — только про тома, которые были гостями, не про системные.
- Состояние держится ≥ 400 ms — защита от дребезга.
- Тишина (`QuietSense`, режим фокуса, полный экран): облачко выключено, реакции только глазами, `fun` выключен полностью. Исключение — `wait_you`, он показывается глазами и одним облачком. Тихие часы не глушат ответ на твоё действие (`answersUser`: взаимодействие, кабель зарядки) **[решение]**.
- Кулдауны и дневные лимиты переживают перезапуск приложения (`ReactionLedger` → `reactions.json`) **[решение]**: иначе после каждого запуска звучало бы уже сказанное сегодня. При выходе память дня и журнал реакций пишутся сразу (не ждут десятиминутной отметки); `install.sh` закрывает приложение мягко, принудительно — только если не закрылось за 3 s.
- Пороги с гистерезисом: батарея «голодная» при < 20%, «сытая» снова при > 30%, иначе реакция мигает.

## Тело

Ровно три элемента: круглое тело с белым свечением, два глаза — сплошные чёрные вертикальные овалы. Плюс мягкая тёмная тень под свечением для читаемости на светлом фоне (визуально часть свечения). Никаких новых элементов ни для одной реакции — пот, слёзы, рот, брови, аксессуары запрещены. Всё выражается пятью параметрами:

| Параметр | Диапазон | Что выражает |
|---|---|---|
| `gaze` (x, y) | −1…1 | направление взгляда, оба глаза вместе; дальний глаз сужается до 85% |
| `eyeScaleY` | 0…1.2 | моргание, сон, прищур, удивление |
| `eyeShape` | овал ↔ дуга «^» | радость |
| `body` (offset, scale, rotation) | ±3 pt, 0.92…1.08, ±8° | прыжок, сжатие, кивок, покачивание |
| `glow` (radius, opacity, warmth) | — | дыхание, акцент, ночью — тёплый белый. Свечение широкое и размытое и всегда пульсирует **[решение]**: размер ×0.88…1.08, яркость — мягко, ±15%; период 3.4 s; во сне — CA-анимация |

### Облик Agent Pals **[решение]**

Классический круг остаётся по умолчанию и как запасной вариант. Выбор — «Настройки → Основное → Облик → Кто на маскоте» (`mascot.skin`: `default` или `agent-pals/<Бот>`). Пак ставится локально: `scripts/install-agent-pals.sh путь/к/паку.zip [Бот]` → `~/Library/Application Support/AgentPulse/Skins/AgentPals/<Бот>/<Клип>.json`; бот без всех 13 клипов не предлагается. Лицо и реквизит (книга, клавиатура, наушники, пот) рисует клип — это осознанное исключение из «ровно три элемента»; тело (сдвиг, масштаб, сжатие, наклон, лёгкий наклон к взгляду) по-прежнему задаёт процедурная поза, поэтому прыжки, тычки, бросок и поглаживание работают как раньше. Свечение у бота выключено, тень слабее (своя светотень). Тело бота центрируется по замеру (центр тела в кадре — 111.5 из 200, ширина — 107), поэтому на любом размере оно на линии хвостика облачка. «Настройки → Основное → Облик → Сценарии: анимации и облачка» — 18 настоящих ситуаций (задача от «Ага, беру» до «Готово», разрешение, долгая задача, наведение, батарея, перегрев, утро, сон): на фоне настоящего угла экрана владельца — снимок `Resources/Scenes/DeskCorner.png` (1140×510 px = сцена 570×255 pt @2x, свой маскот закрашен; показывать разрешено **[решение]**), без снимка — фон, нарисованный по его замерам, живой маскот (свой `MascotAnimator` в нужном состоянии: дыхание, покачивание, наклон, прыжки «ждёт тебя», реакции итога, зевок, вздрагивание — повторяются по кругу) и облачко с теми же репликами из `Phrases`/`ReactionCatalog`, заголовками и иконками приложений, хвостик в 8 pt от тела, как на экране.

Какой бот на маскоте — `PalWardrobe` (Core, покрыт тестами). Бот меняется сам и **не привязан к агенту или программе** **[решение]**: работаешь ли ты в Orca, Claude Code или ChatGPT — неважно.
- Режим «Меняется сам» (`agent-pals/shuffle`, прежний `agent-pals/daily` читается так же). Повод — начало: новая задача (маскот из покоя или сна начинает думать или работать) и пробуждение. Посреди работы бот не меняется.
- Не чаще раза в 3 мин; пока агент ждёт тебя — никогда.
- Все установленные боты (18) идут «мешком»: случайный порядок, без повторов, пока не покажутся все; новый мешок не начинается с только что показанного.
- Можно выбрать и постоянного бота или светящийся круг.
- Переодевание: старый бот сжимается до 0.55 и тает за 0.16 s, новый выпрыгивает 0.55 → 1.1 → 1 за 0.42 s; клип состояния не сбивается.

Смена клипов — `PalChoreographer` (Core, покрыт тестами):

| Состояние | Клип |
|---|---|
| сон | Sleeping (наведение или облачко — сразу Idle) |
| покой | Idle |
| думает | Thinking |
| ждёт тебя | Listening — «слушаю тебя», вытесняет всё сразу |
| читает / ищет / запускает | Reading / Searching / Typing |
| правит код / макет в Figma | Coding / Designing |
| прочая работа | Working |
| готово / ошибка | Done / Error — разово, две петли, затем текущее состояние |

Правила: клип держится не меньше одной своей петли (2.4 s, Working — 3.2 s), между двумя рабочими — не меньше двух: показывается характер работы, а не каждый инструмент; применяется последнее желание. Без задержек — «ждёт тебя», выход из ожидания, засыпание и пробуждение. Итог не перебивает ожидание. Смена — кроссфейд 0.22 s: у всех клипов один кадр 200×200 и одна посадка. Reduce Motion — стоп-кадр; скрытая панель — клипы на паузе. Writing и бот на каждый источник пока не используются.

Геометрия при диаметре 48 pt: глаза 7.5×10.5 pt, центры ±7.5 pt по X, −2 pt по Y. Сдвиг глаз ±6 pt по X, ±4 pt по Y.

Маскот не застывает **[решение]**: в покое раз в 10–25 s сам присматривается (наклон и взгляд), косится, подпрыгивает, моргает; во сне раз в 30–80 s улыбается во сне «^ ^», приоткрывает глаза или ворочается. Это движения тела без облачка, вне бюджета приколов; во сне кадры включаются только на время движения.

Знакомство при первом запуске **[решение]** (`Introduction`): облачка «Мы с тобой» по очереди — «Привет, я тут живу» (прыжки), «Слежу, как себя чувствует твой Mac», «Смотрю прямо на тебя — значит, жду тебя» (на это время поза `wait_you`, только тело — без облачка ожидания и уведомления), без хуков — «Подключи Claude Code — покажу, когда он ждёт», «Погладь меня курсором, мне приятно». Тишину не нарушает: ждёт конца тихих часов, созвона и твоего присутствия; засчитывается (`introduced` в конфиге), только когда показано. `--intro` — показать ещё раз сразу.

Пока висит облачко, маскот не спит **[решение]**: глаза открыты, «Zzz» нет, как при наведении; облачко ушло — засыпает снова. Исключение — «Вздремну».

Базовая пластика: моргание 70/110 ms, интервал 2.5–6 s, 15% двойное; саккады 120–180 ms spring без перелёта; при большой саккаде в 30% случаев моргание. Курсор в радиусе 120 pt — глаза следят.

### Состояния агентов

| Состояние | Поведение |
|---|---|
| `think` | взгляд вверх-в сторону, фиксации 1.5–3 s, прищур 0.85 |
| `work` | смотрит по сторонам; модусы: `read` (сканирует строки), `edit` (вниз, сосредоточен), `run` (следит за точкой), `search` (далеко в стороны) |
| `wait_you` | смотрит прямо на тебя, глаза 1.15, каждые 3 s прыжок + двойное моргание, до реакции |
| `done` | глаза-дуги, два прыжка, вспышка |
| `error` | глаза сжимаются, встряска, свечение гаснет |
| `resting` | агент упёрся в лимит: сессия отдыхает до сброса; маскот засыпает, только если другие агенты не заняты и не ждут; это не ошибка |

Агенты только наблюдаются: Claude Code hooks (`UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Notification`, `SubagentStop`, `Stop`, `StopFailure`, `SessionEnd`) и каналы из раздела «Каналы агентов» **[решение]**. Несколько агентов — список в меню, без счётчика у маскота **[решение]**; пока агент рисует в Figma, над маскотом зеркало фрейма **[решение]**. Клик по маскоту в агентном состоянии открывает окно источника (macOS сам переключит Space). Никакого одобрения или ввода из маскота.

## Голос

Облачко с хвостиком к маскоту, чёрное с тонким краем, Geist, как Пульт **[решение]**: сверху заголовок — категория, к чему относится реплика (иконка слева, 13 pt semibold, белый), ниже суть (12 pt, белый 75%); тёмные цвета категорий на чёрном светлеют. Работа агента — значок приложения (Claude, Figma) и его название («Claude Code», «Claude Cowork»); остальное — иконки Solar Bold из box-ui, у каждой категории свой цвет: Новости дизайна (palette, синий), Батарея (battery-charge, зелёный), Самочувствие (heart-pulse, красный), Сеть (wi-fi-router-round, бирюзовый), Вокруг меня (devices, индиго), Наш день (sun, оранжевый), Праздник (confetti, золотой), Мы с тобой (hand-heart, розовый), Настроение (emoji-funny-circle, фиолетовый), Отдых (moon-sleep, серо-синий). Категория — по id реакции (`BubbleCategory`). `--bubble-sheet out.png` рисует все категории.

При наведении **[решение]** (`HoverStory`), по порядку: пока агент занят — что делаю сейчас («Работаю 12 мин, сделано 8 шагов», «Жду твоего разрешения уже 3 мин»); если ты вернулся, а агенты что-то сделали — итог отсутствия («Пока тебя не было, у меня готовы 3 задачи…»); вечером, если последнее сообщение старше 30 мин, — итог дня, в пятницу вечером и в выходные — недели («За неделю сделана 21 задача»); иначе последнее сообщение целиком, со светлым «5 мин назад» (под новостью — «· ещё 2», сколько свежих ждёт); если сказать нечего — «Я тут». Технических строк (имя источника, проект, статус фазы) в облачке нет — они только в меню. Клик по наведённой новости открывает статью. Сторона — противоположная краю экрана. Появление scale 0.6 → 1 от хвостика, 180 ms; маскот на 300 ms смотрит на облачко.

Правила языка:
- Коротко: ориентир до 10 символов, жёсткий предел — 10 слов **[решение]**; `…` — один символ. Предел проверяется тестом.
- Мягко и по-человечески, как реплика через плечо. Говорит от себя, как живой **[решение]**: «У меня готово, проверь», «Я жду тебя», «Мне жарко…».
- Без прошедшего времени с родом («устал», «понял», «нашёл»): у существа нет пола. Вместо этого — настоящее время, «у меня», безличное («нашлось», «не вышло»). Проверяется тестом.
- Облачко держится не меньше времени чтения: ~1 s заметить + 15 знаков в секунду, не больше 12 s. Ширина до 220 pt, до 4 строк.
- Без техники: никаких «CPU», «RAM», «Wi-Fi», «Bash», «агент».
- Пул 2–4 варианта на реакцию, без повтора подряд; варианты могут зависеть от настроения: в радости добавляются «Ура», «Красота», «О, давай»; уставший договаривает с «…» («Готово…»). «Ждёт тебя» не окрашивается никогда.
- Восклицательный знак — только в радости и не чаще раза в день.

У каждой темы свой заголовок облачка и иконка Solar Bold: Новости дизайна (palette, синий), Новости ИТ (code-square, графит), Экономика (graph-up, зелёный), Наука (atom, тёмно-бирюзовый), Искусство (gallery, терракотовый), Игры (gamepad, жжёный оранжевый), Космос (rocket, тёмно-синий). Рядом с заголовком светлым — источник («Хабр», «Ведомости»). Темы включаются по отдельности в меню «Новости». Одна история из нескольких изданий рассказывается один раз (больше половины значимых слов совпадает).

Источники — только русскоязычные, публичные RSS и открытые Telegram-каналы через веб-версию `t.me/s/канал` (без аккаунта и ключей) **[решение]**:
- Дизайн: Хабр «Интерфейсы», «Дизайн» (фильтр по теме), «Веб-дизайн», «Юзабилити», «Типографика», «Доступность»; «Дизайн-кабак»; Sostav и Cossa (фильтр по теме); Telegram: UX Notes, Figma, Ozon Design (фильтр по теме).
- ИТ: Хабр «Новости», 3DNews, iXBT; Telegram: Техномедиа.
- Экономика: «Ведомости» и «Коммерсантъ» (рубрики экономики); Telegram: The Bell.
- Наука: N + 1, Naked Science, «Популярная механика».
- Искусство и архитектура: The Art Newspaper Russia; Telegram: Archi.ru, Эрмитаж, Музей «Гараж».
- Игры: StopGame, «Игромания»; Telegram: DTF.
- Космос: Хабр «Астрономия»; Telegram: Роскосмос, astronomy.ru.

Суть — без внешних сервисов (`NewsGist`). У новостных лент и Telegram заголовок (первая строка поста) и есть суть: без цитаты-говорящего («Котяков: МРОТ…» → «МРОТ…»), без «[Перевод]», «(видео)», рубрики после «//»; длинный — до двоеточия или тире. У статей суть ищется в анонсе: вступления, рассказ автора о себе, разговорные заходы, цитаты и обрывки, которые без соседнего текста непонятны («Его назвали…», «Об этом сообщила…», «…:»), пропускаются. Пересказ: заголовок-вопрос — «Тут разбирают, как сделать…», «Тут объясняют, почему…»; канцелярит — разговорным; без ссылок, хэштегов, эмодзи, скобок и точки в конце. Не рассказываются: реклама, курсы, вакансии, дайджесты, викторины и тесты, тяжёлые темы (гибель, атаки, война, аресты, суды, политика) и 18+ — маскот для настроения, а не для тревоги.

Вкус **[решение]** (`NewsDesk.record`): открыл статью или «мило» — тема и источник +1, «бесит» — −2 (очки −6…10, в `news.json`). Тема среди не-дизайна выбирается по весу `1 + 0.3 × очки` (от 0.2 до 4): что открываешь — звучит чаще, что бесит — реже, но не пропадает; источник с −4 и ниже молчит, пока есть другие. Доля дизайна (65%) от вкуса не зависит. «Бесит» на новость идёт во вкус, а не в глушилку реакций — новости целиком не выключаются.

Загрузка раз в час. Правила **[решение]**: новость каждые 15 минут, пока ты рядом и не занят (не в тишине, не пока работает агент), с 9 до 22; в выходные тише — раз в 45 минут и без рабочих тем (ИТ, экономика), пока есть другие. Поводы делят один интервал: обычный, утренний до 11:00 (заход «Утренние новости») и сразу после перерыва > 20 мин («Пока тебя не было, нашлось интересное»); источники чередуются; показанное помнится локально (`news.json`). Это осознанное исключение из «Присутствие, не функционал» и «Ничего не уходит с машины»: приложение делает GET к публичным лентам и страницам каналов, без данных пользователя.

## Пульт **[решение]**

Активный виджет в углу напротив маскота: анкер маскота справа — Пульт слева, и зеркально. Капсула — на уровне Dock, как маскот: по центру его полосы, в 16 pt от края экрана, а Dock задаёт предел её ширины (длина оценивается по `tilesize` и числу иконок из `com.apple.dock`, названия не читаются). Раскрытая панель стоит над Dock на те же 16 pt **[решение]**: высота берётся из `visibleFrame`, поэтому панель сама идёт за Dock, а если он скрыт — стоит над капсулой. Перетаскивание маскота Пульт не двигает. Подробности — в ТЗ «Пульт» (Claude Doc); здесь то, что уже в коде (Р1).

- Панель `ConsolePanel`: как у маскота, но раскрытая становится key (Esc, дальше поле суфлёра). Свёрнутая фокус не забирает. В полном экране скрыт; ⌃⌥X показывает его поверх на время раскрытия. Клавиша — `RegisterEventHotKey`, Input Monitoring не нужен.
- Состояния: точка (нечего показывать), капсула (наведение ничего не меняет **[решение]**), раскрытый над капсулой 640 × 250, колонками по горизонтали, тревога (красная рамка, разово, уходит после 8 s ввода). Как у референса, маскот — маленькая деталь рядом с именем сервиса, который работает (общий аниматор с маскотом в углу); инструментов у него по-прежнему нет.
- По умолчанию в капсуле всегда лимиты **[решение]**, нет данных — прочерк; выше них только запись и суфлёр, встреча за 2 мин и тревога лимита. Музыка и полка видны монохромными значками, лидерами становятся, только если модуль лимитов выключен.
- `ConsoleDirector` решает, кто лидер: держится ≥ 8 s, кроме перехода вверх. Пока агент ждёт — смена без анимации, тревоги откладываются, раскрытый Пульт не трогается.
- Новый модуль = протокол `ConsoleModule` + регистрация. Мозг получает только `ToolSignal` — перечисление без строк, проверяется тестом.
- Календарь (Р2): EventKit только на чтение, выключен, пока ты сам не включишь (спросит доступ). Встреча за 2 мин — лидер с обратным отсчётом и «Войти», сигнал маскоту — за 10 мин (Zoom, Meet, Teams, Телемост — из URL, места и заметок, обёртки Outlook и Google разворачиваются). Идущий звонок со ссылкой и не на весь день — тишина маскота сразу, сигналом от Пульта. За минуту — тревога, в полном экране — уведомление.
- Полка (Р2): только ссылки на файлы, в памяти; выход очищает. Файл — на Пульт или на тело маскота (съедает: «Ням, положу»); мозг получает `fileEaten` без имени. Вытащил наружу — файла на полке нет. Снимки экрана — опция: система помечает их атрибутом, название не важно.
- Музыка (Р2): `MediaPlayerSense` с двумя реализациями. Основная — `Vendor/mediaremote-adapter` (BSD-3): фреймворк собирает `scripts/build-media-adapter.sh` без cmake, грузит его системный `/usr/bin/perl`, у него есть доступ к MediaRemote. Два сбоя подряд — «недоступно», запасной AppleScript для «Музыки» и Spotify включается кнопкой. Маскот по-прежнему только покачивается от занятого выхода.
- Оформление **[решение]**: стиль CapaTheNotch (MIT), значения в `ConsoleStyle`: чёрная поверхность с краем 12%, карточки белые 8% с радиусом 20, дуговые шкалы на 270°, Geist (11, 13, 15, 20, 26), радиусы 6, 10, 14, 20, 32, цвета зон 30D158 / FFD60A / FF453A, пружины открытия и закрытия. Страницы — слова без подложек, справа в той же строке значок настроек; листаются ещё свайпом (пальцы вправо — следующая), ← → и цифрами, если курсор не в поле. Жест разбирается в `ConsolePanel.sendEvent`, а не в мониторе: поле и списки забирают прокрутку в свой цикл, и монитор её не видит. Вбок — страницы (`ScrollAxis`, `PageSwipe`: одно движение — одна страница), вверх-вниз — списку. Смена страницы: старая гаснет за 0.08 s, следующая чуть выходит справа, предыдущая слева, на 24 pt. Раскрытие: чёрная форма вырастает из самой капсулы (начинает её размером и на её месте), содержимое проявляется уже в ней, закрытие быстрее и без отдачи. Процент остаётся расходом, а не остатком, как у референса. Его маскот, шторка и логотипы продуктов сюда не входят.
- Подпись: приложение собирается с hardened runtime и `Resources/AgentPulse.entitlements`; без строк назначения в `Info.plist` macOS завершает приложение при первом запросе. `disable-library-validation` нужен из-за локального сертификата без Team ID (иначе не грузится Lottie).
- Суфлёр (Р3): вкладка «Суфлёр» → текст (вставка или .txt/.md) → панель `PrompterPanel` под камерой: на экране со встроенной камерой, с вырезом — из шторки, без выреза — под строкой меню; такого экрана нет — вверху экрана Пульта. 420 pt, 3 строки, текущая по центру и крупнее. Панель не становится key. ⌃⌥P — старт и стоп, ⌃⌥↑ и ⌃⌥↓ — скорость ±10% (стрелки заняты только на время суфлёра), клик — пауза. Время считается по словам. Дочитан — закрывается через 3 s. Последние 5 текстов — `prompter.json` (0600), удаляются кнопкой. «За голосом» выключено: `SFSpeechRecognizer` только на устройстве, нет модели языка — честная ошибка и ручная скорость, а не сеть; тишина 1.5 s — стоп; свой микрофон `QuietSense` созвоном не считает (пока пишем и 5 s после). Тишина и лидер — сразу; маскот смотрит в камеру и не двигается сам. `sharingType = .none` стоит только на суфлёре и выключается в настройках: это не гарантия, у маскота и Пульта флага нет до матрицы захвата.
- Диктовка (Р4): выключена, пока сам не включишь. ⌃⌥D держишь — запись, отпустил — текст; короче 300 ms — ничего, дольше 5 мин — стоп. Распознаёт GigaAM-v3 с пунктуацией (MIT; архив 170 MB, на диске 232 MB, сумма закреплена в `DictationModelSpec`), модель качается кнопкой в настройках. Считает отдельный процесс `pulse-asr` (C, sherpa-onnx по `dlopen`): модель занимает 260–650 MB, и только конец процесса отдаёт их системе; он не трогает микрофон и сеть, звук приходит по stdin, через 2 мин простоя или с выходом приложения процесс завершается. Рантайм качает `scripts/fetch-sherpa.sh` (сумма закреплена, в репозиторий не входит). Запись длиннее 25 s режется по паузам. Английский — системный распознаватель на устройстве, macOS 26+. Вставка (`TextInsertion`): поле через Accessibility с проверкой → ⌘V с возвратом буфера; поле не опознано — ⌘V, текст остаётся в буфере; без Accessibility — только буфер, звук и «Текст в буфере». Пока идёт запись — тишина, маскот смотрит на Пульт, глаза 1.1; Listening не используется. Поверх полного экрана капсула видна на время диктовки. История выключена: только текст, 30 дней, `dictation.json` (0600).
- Переводчик (Р4): ⌃⌥T, macOS 26+, Translation на устройстве, языки ставятся в системных настройках. Выделение — через Accessibility; нет — подсказка, второе нажатие за 60 s берёт буфер, раньше буфер не читается. Вкладка живёт, пока Пульт раскрыт.
- У приложения без меню ⌘V и прочее некому обработать: их передаёт монитор клавиш `ConsolePanel`. Поле суфлёра — свой `NSTextView` без приёма перетаскивания, иначе вместо файла вставился бы путь.
- Лимиты: процент — расход. Claude — обёртка `pulse-statusline` с согласия (исходная команда в base64: открытым текстом её затёрла бы Orca; при удалении приложения команда сама запускает исходную). Codex — `codex app-server` раз в 5 мин и после событий, не чаще раза в минуту; путь и папка аккаунта задаются в настройках (в Orca свой `CODEX_HOME`); `account/read` не вызывается, он возвращает e-mail. OpenCode Go не подключён: это чтение ключа и сетевой запрос.
- Честность: нет данных — «нет данных», не 0%; старше 30 мин — приглушено; сброс считается по времени; пороги 80 и 95 с выходом на 5 п. п. ниже. Уведомление — одно за пересечение «критично» и только когда маскота не видно.
- Реакции: `limit.low`, `limit.critical`, `limit.resting`, `limit.restored`, уровень `body`, по записи на сервис. Реплики без цифр, сервис — в заголовке облачка.

Отладка: `--limits-demo [critical]`, `--console-open`, `--console-tab media`, `--shelf-demo путь`, `--meeting-demo минут [ссылка]`, `--prompter-demo [голос]`, `--menu-demo` (показать меню маскота без правого клика), `--console-sheet папка` (капсула и все страницы в файлы, подставные данные, окон нет, приложение закроется), `--prompter-notch 37` (вид с вырезом на Mac без него), `--dictation-model` (скачать модель), `--dictation-demo файл.wav [секунд]` (весь путь со звуком из файла, 16 kHz; текст в отдельный буфер, настройки не меняются). Демо суфлёра запоминает свой текст в «Недавних».

## Настройки

Минимум, без экранов на десять вкладок:

```json
{
  "version": 1,
  "position": { "anchor": "bottom-right", "screen": "dock", "size": 48 },
  "talkativeness": 0.5,
  "mischief": 0.5,
  "senses": { "agents": true, "body": true, "rhythm": true, "audio": true, "experimental": false },
  "quietHours": { "from": "23:30", "to": "08:00" },
  "birthday": null,
  "hideWhenIdle": { "enabled": true, "afterMinutes": 30 }
}
```

`talkativeness` масштабирует частоту облачков вне агентов, `mischief` — бюджет приколов (0 = без приколов, 1 = до 8 в день). Два слайдера вместо двадцати переключателей.

Окно «Настройки» **[решение]** (⌘, из меню, клик по иконке в Dock или повторный запуск) — одно, разделы в боковой колонке словами без подложек, ⌘1–⌘6; оформление как у Пульта и всегда тёмное: чёрная поверхность, карточки `SettingsBlock`, зелёный переключатель, Geist; пока окно открыто, у приложения есть иконка в Dock. Разделы: «Основное» (что маскот делает сейчас, шкалы настроения, итог дня; угол экрана схемой, дисплей, размер 40–72 pt, показывать маскота, гравитация, запуск при входе), «Характер» (болтливость, озорство, тихие часы, прятаться при простое, день рождения, счётчик «мило/бесит», сброс памяти), «Пульт» (показывать, клавиша раскрытия, модули, лимиты Claude и Codex), «Новости» (темы с источниками), «Источники» (хуки Claude Code, Cowork, браузер, Claude Chat, Figma, органы чувств), «Лаборатория» (бывший MascotLab: состояния, SignalSimulator, реакции вручную, слайдеры `MascotTuning`). Всё сохраняется сразу, без кнопки «Сохранить». Меню по клику на значок и правому клику на маскоте — своё, на языке Пульта (`PulseMenuView`), только ежедневное: кто сейчас работает, «мило/бесит», показывать маскота, рассказывать новости, вернуть в угол, настройки, выйти. Темы новостей — в настройках. `--settings вкладка` открывает окно на вкладке, `--settings-sheet папка` рисует все вкладки картинками в 2x.

## Каналы агентов

Реализуемо, но не одинаково для всех источников. Граница проходит по тому, есть ли у источника наблюдаемый канал событий.

| Источник | Канал | Что видно | Статус |
|---|---|---|---|
| Claude Code (CLI, IDE, вкладка Code в Claude desktop) | Hooks → `pulse-hook` → сокет | Всё: запрос, каждый инструмент, разрешение, итог | **Готово** (MVP) |
| ChatGPT (Codex в приложении ChatGPT, `com.openai.codex`) **[решение]** | Те же хуки → `pulse-hook`: ChatGPT перенимает хуки Claude Code в `~/.codex/hooks.json`. Отличается от Claude Code по приложению-хозяину `com.openai.codex`, пути журнала в `~/.codex/` или полю `turn_id` | Запрос, инструменты, разрешение, итог — как у Claude Code | **Сделано**: источник `codex`, в облачке значок и заголовок ChatGPT. Если хуки Codex зовут `pulse-hook`, Codex из Orca не дублируется. Реальный payload Codex не снят — проверено подставным событием |
| Агенты в Orca (Codex, OpenCode, Gemini, Cursor…) | Снимок `~/Library/Application Support/orca/agent-hooks/last-status.json` (FSEvents): Orca сама ставит хуки своим агентам и переписывает файл, одна запись на панель; события — разница соседних снимков (`OrcaStatus`) | `working` → работает (имя инструмента), `blocked` → ждёт разрешения, `waiting` → ждёт ответа, `done` → итог (`outcome: failure` → ошибка). Текст промпта, ответа и аргументы не читаются | **Сделано** **[решение]**. Формат внутренний (`version: 2`), при другой версии источник «не найден». Вывод: у каждого источника свой канал, но все сводятся к `AgentEvent`; маскот не знает, откуда событие. Глубина разная: Claude Code и Cowork видны полностью, Chat — только «генерирует / ждёт / готово», Figma AI — только «макет меняется». Маскот показывает то, что честно известно: без деталей инструмента — общий `work` или `think`.

Принципы для неофициальных каналов (Cowork-журнал, логи, DOM, Accessibility):
- Только чтение; никакого вмешательства в работу Claude и Figma.
- Читаем типы событий и имена инструментов, никогда — текст сообщений.
- Адаптер проверяет формат; незнакомый формат → источник помечается «недоступен» в меню, а не выдаёт ложные `done`/`error`.
- Каждый канал включается отдельно в настройках.

## Разрешения и приватность

- Базовая версия (Пульт выключен или только Лимиты) не требует ни одного TCC-разрешения: батарея, перегрев, память, сеть, мониторы, сон, простой, тема, аудиоустройства, Caps Lock, занятость микрофона/камеры читаются без запросов.
- Не запрашиваем Screen Recording, Input Monitoring, Full Disk Access, геолокацию. Календари — только при включении модуля в Пульте, на чтение. Микрофон — при первом нажатии ⌃⌥D или с «За голосом» в суфлёре, распознавание речи — с «За голосом» и английской диктовкой; всё на устройстве, аудио не пишется. Automation для «Музыки» и Spotify — только по кнопке запасного пути. Accessibility — только opt-in для чата в Claude desktop, вставки диктовки и чтения выделения, по умолчанию выключен **[решение]**.
- Опционально и явно: статус режима фокуса (если потребует авторизации — по согласию).
- Лимиты Pulse читает локально: обёртка отдаёт в сокет только проценты и время сброса, запросы делает сам Codex.
- Ничего не уходит с машины. Нет аналитики. Память — только агрегаты, 30 дней. Сетевой доступ — загрузка публичных лент и открытых Telegram-каналов с новостями (GET без данных пользователя), выключается в меню «Новости» **[решение]**, и разовая загрузка модели диктовки по кнопке.
- Установка хуков Claude Code — только с согласия, с бэкапом и аккуратным мержем. Команда хука — `"…/pulse-hook" 2>/dev/null || true`: удалили приложение, не сняв хуки, — агенты не видят ошибок. Копии наших хуков у Codex (`~/.codex/hooks.json`, аккаунты Codex в Orca) при запуске получают актуальную команду, «Удалить хуки» снимает их отовсюду, с бэкапами **[решение]**.
- Чужие материалы указаны с авторами: иконки Solar (480 Design, CC BY 4.0), Lottie (Airbnb, Apache 2.0), mediaremote-adapter (Jonas van den Berg, BSD-3), GigaAM (MIT), sherpa-onnx (Apache 2.0), ONNX Runtime (MIT) — `Resources/Licenses`, копия в приложении и строка в «Настройки → Основное → О программе». VoiceOver зачитывает облачко «жду тебя»; остальные реплики — нет.

## Критические ограничения

- `pulse-hook` отвечает < 50 ms и не может замедлить или сломать агента; при недоступном сокете молча `exit 0`.
- Ни один `Sense` не опрашивает чаще раза в 5 s, если есть событийная альтернатива — используется она.
- Физика броска не уводит маскота за пределы видимых областей экранов; позиция хранится на монитор (анкер + отступ), при отключении монитора маскот возвращается на основной.
- Если на экране маскота что-то развёрнуто на весь экран, маскота не видно **[решение]** — он не мешает смотреть и показывать; «ждёт тебя» и «готово» в это время доходят системным уведомлением; пока маскота видно, уведомлений нет — он скажет сам, и текст агента (английские строки Claude Code) в уведомление не попадает **[решение]**. Во время показа экрана — прячется.
- Неофициальные датчики (угол крышки) — только в `Experimental`, за флагом, с graceful fallback.

## Валидация

Характер не проверяется юнит-тестами — проверяется жизнью.

1. После R1 — неделя на своём ноутбуке. В меню две кнопки: «мило» и «бесит» для последней реакции. Лог локальный.
2. Цель: ≤ 1 «бесит» в день и ≥ 3 «мило». Лог `feedback.jsonl` хранится 30 дней. Реакция с двумя «бесит» за неделю переписывается, уходит в глаза без облачка или удаляется. Глаза без облачка — автоматически **[решение]** (`FeedbackLog`): по логу за 7 дней такая реакция молчит; оценка новости идёт во вкус новостей, а не сюда; агентные не глушатся никогда; в меню видно, сколько реакций молчит.
3. Проверка на чужом человеке: дать ноутбук коллеге на час, не объясняя. Если через час он не понял, что значит взгляд прямо на него и «Можно?», — `wait_you` недостаточно ясен.

## Соглашения по коду

- Swift 6 strict concurrency. `Director`, `Mood`, `DayMemory` — значимые типы; общий доступ к мозгу — через `DirectorActor`; рендер, модель тела и органы чувств — `@MainActor`.
- Senses не знают про тело и голос; тело не знает про сигналы. Связь только через `Director` и `ReactionCatalog`.
- Новый орган чувств = один файл в `Senses/` + регистрация. Новая реакция = одна запись в каталоге.
- Все числа пластики — в `MascotTuning`, все пороги и кулдауны — в `ReactionCatalog`. Магических чисел в поведении нет.
- Каждая реакция должна запускаться из `SignalSimulator` — без этого её невозможно настроить.
- Director тестируется на виртуальных часах: приоритеты, бюджеты, кулдауны, гистерезис, тишина.
- Тест реплик: все реплики всех локалей ≤ 10 слов **[решение]**, без техники и без рода («устал», «рада», «готов»); у каждой реакции с `phrases` есть непустой пул.

## Definition of Done для реакции

1. Запись в `ReactionCatalog` с уровнем, кулдауном и лимитом.
2. Поведение использует только пять параметров тела — без новых элементов.
3. Реплики короткие (≤ 10 слов), без рода, без техники; минимум 2 варианта, если реакция может повториться.
4. Запускается из `SignalSimulator`, настроена в `MascotLab`.
5. Тест Director: срабатывает когда надо, молчит в тишине, уважает бюджет.
6. Неделя жизни без «бесит».
