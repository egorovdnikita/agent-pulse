# Agent Pulse

Нативный macOS-виджет поверх всех окон: показывает, что сейчас делает ИИ-агент (Claude Code), пока ты занят другим окном, Space или экраном. Агент — маленький маскот: по его глазам за долю секунды видно, думает он, работает или ждёт тебя.

Главное, что он решает: **не пропустить момент, когда агент ждёт разрешения или ответа**.

> Статус: ранний MVP (релиз 1 в работе). Полный паспорт проекта — [CLAUDE.md](CLAUDE.md).

## Что уже есть

- Claude Cowork: журнал сессии `audit.jsonl` читается с хвоста через FSEvents (~15 ms, без опроса): запрос, инструменты, разрешения, итог.
- Claude Chat на claude.ai и Figma Make в браузере: расширение Chrome (`Extensions/Chrome`) сообщает только состояние страницы — думает, ждёт одобрения, готово — через native messaging.
- Приём событий Claude Code через hooks → `pulse-hook` → unix-сокет (ответ ~10 ms, всегда `exit 0`, агент не блокируется).
- Стейт-машина на сессию, несколько сессий параллельно, приоритет `wait_you > error > done > work > think > idle > sleep`.
- Очеловечивание инструментов («Правит Package.swift», «Запускает тесты», «Рисует в Figma») и схлопывание серий чтений в «Изучает проект».
- Процедурный маскот (SwiftUI `Canvas` + `TimelineView`): 5 состояний, 4 модуса работы, 4 реакции, моргание, саккады, слежение за курсором, Reduce Motion.
- Облачко-реплика до 10 слов с очередью, приоритетами и троттлингом.
- В покое спит в правом нижнем углу дисплея с Dock: закрытые глаза и «Zzz». При наведении плавно просыпается и рассказывает о последнем запросе: Claude или Figma, проект, статус, когда.
- Системные уведомления на «ждёт тебя» и «готово».
- Установщик хуков с бэкапом `~/.claude/settings.json` и чистым откатом.
- MascotLab — окно для настройки движения вживую.

Дальше по [roadmap](CLAUDE.md#roadmap): Figma MCP-прокси и зеркало Figma (релиз 2), история и таймлайн (релиз 3).

## Сборка

Нужны macOS 14+ и Swift 6 (хватает Command Line Tools, Xcode не обязателен).

```bash
scripts/bundle.sh            # → build/AgentPulse.app
open build/AgentPulse.app
```

В меню-баре появится значок. «Установить хуки Claude Code…» добавит хуки в `~/.claude/settings.json` (с бэкапом рядом). Чужие хуки не трогаются; удаление возвращает файл к исходному виду.

Claude в браузере: в меню «Подключить Claude в браузере…», затем `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → открывшаяся папка `~/Library/Application Support/AgentPulse/ChromeExtension`.

Посмотреть маскота без настоящего агента:

```bash
scripts/demo-events.sh
```

Тесты:

```bash
scripts/test.sh
```

## Устройство

```
Sources/
  AgentPulseCore/   ядро без UI: AgentEvent, SessionStore, Humanizer, реплики, маппинг в состояния маскота, конфиг, установщик хуков, сокет
  AgentPulse/       menu bar приложение: NSPanel-оверлей, маскот, облачко, уведомления, MascotLab
  pulse-hook/       хук Claude Code: stdin → сокет (только Darwin, без Foundation)
Tests/              Swift Testing
```

Источники не знают про UI, UI не знает про источники — только `AgentEvent` и `Phase`. Новый источник = один адаптер.

## Приватность

Ничего не уходит с машины. Текст промптов не читается и не логируется. Сокет доступен только владельцу (`0600`). Screen Recording и Accessibility не нужны.
