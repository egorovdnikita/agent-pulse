# Agent Pulse

Живой характер ноутбука для macOS. Маленький светящийся круг с глазами живёт поверх всех окон на всех рабочих столах: показывает, как себя чувствует Mac и что делают ИИ-агенты. Говорит короткими репликами в облачке, реагирует на тебя, на время суток и на состояние железа, иногда шутит — в строгом дневном бюджете.

Главное: **не пропустить момент, когда агент ждёт тебя** — маскот смотрит прямо на тебя и подпрыгивает. Полный паспорт проекта — [CLAUDE.md](CLAUDE.md).

## Что умеет

- **Агенты.** Claude Code и Codex — через хуки → `pulse-hook` → unix-сокет (ответ ~10 ms, всегда `exit 0`). Агенты в Orca — снимок её статуса. Claude Cowork — журнал `audit.jsonl`. Claude на claude.ai и Figma Make — расширение Chrome. Figma AI — плагин-компаньон с зеркалом фрейма над маскотом.
- **Состояния:** думает, работает (читает, правит, запускает, ищет), ждёт тебя, готово, ошибка; покой и сон. Несколько агентов сразу — список в меню, маскот показывает самого важного. Увиденное ожидание уступает работе других агентов.
- **Тело ноутбука:** батарея и кабель зарядки, перегрев, память, диск, сеть и «интернет через телефон», флешки и iPhone, мониторы, сон, заставка, звук, наушники, Caps Lock, часовой пояс. Только системные сигналы — без чтения окон, файлов, буфера и названий приложений.
- **Ритм:** приветствия, перерывы, поздний вечер, выходные, сезоны, годовщины знакомства.
- **Ты:** следит за курсором, его можно гладить (трекпад мурчит), тыкать, перетаскивать и бросать.
- **Новости** дизайна и не только — из публичных русскоязычных лент, раз в 15 минут, пока ты рядом и не занят.
- **Облик:** светящийся круг или боты Agent Pals (Lottie; пак платный и в репозиторий не входит).
- **Тишина:** созвон, полный экран, тихие часы — реакции только глазами. Пока маскота не видно, «ждёт тебя» и «готово» приходят системным уведомлением.
- Окно «Настройки» с лабораторией: ручные состояния, симулятор любого сигнала, слайдеры пластики.

Замер на MacBook M2: процессор 0.7–2.6%, память 31–44 MB.

## Запуск

Нужны macOS 14+ и Swift 6 (хватает Command Line Tools, Xcode не обязателен).

```bash
scripts/install.sh --login   # сборка → "/Applications/Agent Pulse.app", запуск при входе
```

В меню-баре появится значок; хуки Claude Code ставятся из его меню. Маскот без настоящего агента: `scripts/demo-events.sh`. Тесты: `scripts/test.sh`. Подключение Chrome, Figma, Agent Pals и удаление — в [docs/setup.md](docs/setup.md).

## Устройство

```
Sources/
  AgentPulseCore/   ядро без UI: события и сессии агентов, адаптеры источников, мозг (Director, каталог реакций,
                    настроение, память дня), облачко и реплики, новости, конфиг, установщики
  AgentPulse/       menu bar приложение: оверлей, маскот на слоях Core Animation, органы чувств, настройки, лаборатория
  pulse-hook/       хук Claude Code и Codex: stdin → сокет (только Darwin, без Foundation)
Extensions/Chrome/  расширение для claude.ai и Figma Make
FigmaCompanion/     плагин-компаньон Figma
Tests/              Swift Testing
```

Органы чувств не знают про тело и голос, тело не знает про сигналы — связь только через `Director` и `ReactionCatalog`. Новый источник агентов = один адаптер, новая реакция = одна запись в каталоге.
