# Agent Pulse

Живой характер ноутбука для macOS: светящийся круг с глазами поверх всех окон показывает, как себя чувствует Mac и что делают ИИ-агенты. Рядом — Пульт: лимиты нейросетей, суфлёр, полка файлов, переводчик и диктовка.

![Обложка](docs/assets/cover-agent-pulse.png?v=2)

## Что умеет

- **Агенты.** Главное — не пропустить момент, когда агент ждёт тебя: маскот смотрит прямо на тебя и подпрыгивает. Claude Code и Codex — через хуки → `pulse-hook` → unix-сокет (ответ ~10 ms, всегда `exit 0`). Агенты в Orca — снимок её статуса. Claude Cowork — журнал `audit.jsonl`. Claude на claude.ai и Figma Make — расширение Chrome. Figma AI — плагин-компаньон с зеркалом фрейма над маскотом.
- **Состояния.** думает, работает (читает, правит, запускает, ищет), ждёт тебя, готово, ошибка; покой и сон. Несколько агентов сразу — список в меню, маскот показывает самого важного. Увиденное ожидание уступает работе других агентов.
- **Тело ноутбука.** Батарея и кабель зарядки, перегрев, память, диск, сеть и «интернет через телефон», флешки и iPhone, мониторы, сон, заставка, звук, наушники, Caps Lock, часовой пояс. Только системные сигналы — без чтения окон, файлов, буфера и названий приложений.
- **Ритм.** Приветствия, перерывы, поздний вечер, выходные, сезоны, годовщины знакомства. Говорит короткими репликами в облачке, иногда шутит — в строгом дневном бюджете.
- **Ты.** Следит за курсором, его можно гладить (трекпад мурчит), тыкать, перетаскивать и бросать.
- **Новости.** Дизайн и не только — из публичных русскоязычных лент, раз в 15 минут, пока ты рядом и не занят.
- **Облик и настройки.** Светящийся круг или боты Agent Pals (Lottie; пак платный и в репозиторий не входит). Окно «Настройки» с лабораторией: ручные состояния, симулятор любого сигнала, слайдеры пластики.
- **Тишина.** Созвон, полный экран, тихие часы — реакции только глазами. Пока маскота не видно, «ждёт тебя» и «готово» приходят системным уведомлением.

### Пульт

Капсула в углу напротив маскота, на уровне Dock; ⌃⌥X раскрывает панель. В «Настройки → Модули» можно выбрать короткое одиночное нажатие Shift; для него нужен Универсальный доступ. Маскот — характер, Пульт — инструменты: ввод, команды и голос есть только здесь. Каждый модуль включается отдельно.

- **Лимиты.** Пятичасовой и недельный расход Claude Code (обёртка statusline, с согласия) и Codex (`codex app-server`). Нет данных — прочерк, а не 0%; предупреждение при 80 и 95%.
- **Суфлёр.** Текст бежит под камерой, у выреза экрана: скорость клавишами (⌃⌥P, ⌃⌥↑↓) или «за голосом» — распознавание на устройстве.
- **Библиотека.** Полка файлов: бросаешь на Пульт или на маскота, вытаскиваешь куда нужно. Только ссылки, в памяти.
- **Переводчик.** Перевод на устройстве (macOS 26+); ⌃⌥T приносит выделенный текст.
- **Диктовка.** Держишь ⌃⌥D — говоришь, отпустил — текст в поле. Русский — GigaAM-v3 с пунктуацией в отдельном процессе `pulse-asr`, английский — системный распознаватель; всё на устройстве, звук не пишется.

Замер на MacBook M2: процессор 0.7–2.6%, память 31–44 MB (с Пультом — до 3.5% и 39 MB).

## Запуск

Нужны macOS 14+ и Swift 6 (хватает Command Line Tools, Xcode не обязателен).

```bash
scripts/install.sh --login   # сборка → "/Applications/Agent Pulse.app", запуск при входе
```

В меню-баре появится значок; хуки Claude Code ставятся из его меню. Маскот без настоящего агента: `scripts/demo-events.sh`. Тесты: `scripts/test.sh`. Модель диктовки качается кнопкой в настройках. Подключение Chrome, Figma, Agent Pals и удаление — в [docs/setup.md](docs/setup.md).

## Устройство

```
Sources/
  AgentPulseCore/   ядро без UI: события и сессии агентов, адаптеры источников, мозг (Director, каталог реакций,
                    настроение, память дня), облачко и реплики, новости, ядро Пульта, конфиг, установщики
  AgentPulse/       menu bar приложение: оверлей, маскот на слоях Core Animation, органы чувств, Пульт,
                    суфлёр, диктовка, переводчик, настройки, лаборатория
  pulse-hook/       хук Claude Code и Codex: stdin → сокет (только Darwin, без Foundation)
  pulse-statusline/ обёртка statusline Claude Code: копия лимитов в сокет, затем исходная команда
  pulse-asr/        помощник диктовки на C: звук по stdin → текст; модель выгружается вместе с процессом
Extensions/Chrome/  расширение для claude.ai и Figma Make
FigmaCompanion/     плагин-компаньон Figma
Tests/              Swift Testing
```

Органы чувств не знают про тело и голос, тело не знает про сигналы — связь только через `Director` и `ReactionCatalog`. Новый источник агентов = один адаптер, новая реакция = одна запись в каталоге.
