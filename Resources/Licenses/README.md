# Чужие материалы в Agent Pulse

- **Solar Icons**, стиль Bold — иконки категорий облачка. Авторы: 480 Design. Лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Геометрия взята из `@box-ui/icons` без изменений, перекрашивается в цвет категории.
- **Lottie** (lottie-ios / lottie-spm) — проигрывание анимаций ботов. Авторы: Airbnb. Лицензия Apache 2.0, полный текст — `Lottie-Apache-2.0.txt`. Фреймворк встроен в приложение без изменений.
- **Agent Pals** (UI8) — платный пак анимаций ботов. В репозиторий и приложение не входит: ставится владельцем лицензии локально (`scripts/install-agent-pals.sh`).
