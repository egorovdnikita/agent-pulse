# Чужие материалы в Agent Pulse

- **Solar Icons**, стиль Bold — иконки категорий облачка. Авторы: 480 Design. Лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Геометрия взята из `@box-ui/icons` без изменений, перекрашивается в цвет категории.
- **Lottie** (lottie-ios / lottie-spm) — проигрывание анимаций ботов. Авторы: Airbnb. Лицензия Apache 2.0, полный текст — `Lottie-Apache-2.0.txt`. Фреймворк встроен в приложение без изменений.
- **Agent Pals** (UI8) — платный пак анимаций ботов. В репозиторий и приложение не входит: ставится владельцем лицензии локально (`scripts/install-agent-pals.sh`).

## mediaremote-adapter

Jonas van den Berg и участники, BSD 3-Clause: `mediaremote-adapter-BSD-3-Clause.txt`. Исходники — `Vendor/mediaremote-adapter`.

## Диктовка

- **GigaAM-v3** — модель распознавания русской речи. Авторы: GigaChat Team. Лицензия MIT: `GigaAM-MIT.txt`. Модель не входит в приложение, скачивается кнопкой в настройках. Некоммерческая лицензия относилась только к модели 2024 года, она не используется.
- **sherpa-onnx** — движок распознавания. Авторы: k2-fsa. Лицензия Apache 2.0: `sherpa-onnx-Apache-2.0.txt`. Заголовок `Sources/pulse-asr/include/c-api.h` взят без изменений.
- **ONNX Runtime** — Microsoft. Лицензия MIT: `onnxruntime-MIT.txt`.

## Оформление Пульта

- **Geist** — шрифт Пульта. Авторы: The Geist Project. Лицензия SIL OFL 1.1: `Geist-OFL.txt`.
- **CapaTheNotch** — референс оформления: значения цветов и шкал, значок Claude и файл значка OpenAI. Лицензия MIT: `CapaTheNotch-MIT.txt`.
