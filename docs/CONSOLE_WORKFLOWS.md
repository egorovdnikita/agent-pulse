# Быстрые действия Пульта

Пульт сохраняет четыре вкладки. Переключение — ⌘1–⌘4, даже когда курсор в редакторе.

## Библиотека

Начни печатать имя — выделится совпадение. Через секунду паузы начинается новый запрос; повтор одной буквы перебирает совпадения. Стрелки перемещают выделение, Shift расширяет его.

Правый клик по файлу открывает закрепление, перенос в начало группы, Finder и остальные действия. Для сортировки открой контекстное меню свободного места Библиотеки. Перетаскивание внутри сетки меняет порядок в пределах группы закреплённых или обычных файлов. ⌘Z отменяет изменение, ⇧⌘Z повторяет. Оригиналы не изменяются.

Пробел открывает Quick Look с выбранного файла, стрелки перелистывают доступные файлы. Esc возвращает в Пульт. Для .txt / .md есть «Открыть в Докладчике»: UTF-8, до 2 МБ.

## Переводчик

Выдели часть исходного текста → правый клик → «Перевести выделенный фрагмент». Справа получится текст с заменой только этого фрагмента. Остальные части сохранятся.

Выдели название → «Не переводить этот термин». Повторное выделение позволяет снять защиту; весь список находится в настройках модуля «Перевод». Регистр термина учитывается.

Удерживай Option, чтобы временно увидеть оригинал справа. ⇧⌘C копирует результат без форматирования. После очистки готового перевода правый клик по карточке результата позволяет его восстановить. После выхода из приложения результат забывается.

## Докладчик

Выдели отрывок в редакторе → «Репетировать фрагмент». Полный черновик и прежнее место чтения остаются на месте.

Правый клик по «Старт» / «Продолжить» открывает:

- «Длительность выступления…»: минуты (`5`, `2,5`) либо м:с (`2:30`). При недостижимом времени показывается реальная длительность в комфортном диапазоне темпа.
- «Паузы по разметке»: пустая строка даёт секунду, отдельная строка `[пауза]` — две секунды, `[пауза 2,5]` — указанную паузу. Маркеры не показываются в читаемом тексте. Режим сохраняется; голосовое следование не ждёт таймер паузы.

Во время чтения ⌃⌥⌫ возвращает на начало предложения. Та же команда — в меню кнопки «Стоп».

## Диктовка

В прежних правилах можно перечислять варианты через `|`: `айфон | ай фон → iPhone`. Галочка «Точно» сохраняет регистр написания, включая начало предложения.

«Голосовая разметка» включается отдельно в настройках диктовки. Тогда «новый абзац», «новая строка», «новый пункт» становятся форматированием; в обычном режиме это слова.

После диктовки поставь курсор в нужное поле и нажми ⌃⌥V для повторной вставки. Доступно две минуты, даже без постоянной истории. Та же команда — в контекстном меню капсулы. Она использует прежнее разрешение на вставку; без него текст остаётся в буфере.

## Лимиты и агенты

Нажми на шкалу лимита: появятся источник, время снимка и сброса. Сведения можно скопировать.

В системном меню раскрой строку ожидающего агента → «Напомнить через 10 минут». Напоминание отменяется, если агент продолжил работу; новый эпизод ожидания не наследует старый таймер. В том же меню можно отменить назначенное напоминание вручную.
