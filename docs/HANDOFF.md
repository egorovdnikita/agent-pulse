## Сборка и проверка

Xcode нет, только Command Line Tools.

- Сборка: `source scripts/env.sh && swift build "${SWIFT_FLAGS[@]}" -c release` (`--build-system native` и путь к Testing уже в `env.sh`).
- Тесты: `scripts/test.sh` — 364 теста, Swift Testing, все зелёные на 2026-11-08.
- Установка: `scripts/install.sh` — собирает, подписывает, кладёт в `/Applications/Agent Pulse.app` и перезапускает. Перед словом «готово» — всегда установить.
- Перезапуск с аргументами: сначала дождаться выхода (`osascript -e 'tell application id "io.github.egorovdnikita.agentpulse" to quit'`, затем подождать 3–4 s), иначе `open --args` теряет аргументы.
- Отладочные флаги перечислены в `CLAUDE.md` (раздел «Пульт», «Отладка»): `--console-sheet папка`, `--settings-sheet папка`, `--settings вкладка`, `--menu-demo`, `--limits-demo`, `--console-open`, `--shelf-demo путь`, `--bubble-sheet файл`.

### Снимки экрана

Снимать **только окна приложения**: `screencapture -x -o -l <id окна>`, id — из `CGWindowListCopyWindowInfo` по владельцу «AgentPulse». Весь экран не снимать: на нём личные окна владельца (так уже было один раз).

## Аудит 2026-11-08 (полный, только список)

Порог — P0 и P1 с доказательством. Подробности и «на потом» — в `docs/AUDIT_LOG.md`.

### P0

1. **Сборка на GitHub Actions падает с релиза Р2 (`8d49d9d`), все запуски после него красные.** Раннер `macos-15` со старым Swift не принимает неявное приведение кортежей `CGFloat` ↔ `Double`:
   - `Sources/AgentPulse/Console/PrompterPanel.swift:129` — `return (measure(before), measure(words[index]))` при типе `(start: Double, width: Double)`;
   - `Sources/AgentPulse/Console/TrackpadGesture.swift:205–206` — `surface.width` / `surface.height` у кортежа `(Double, Double)`.
   Доказательство: `gh run view 42452338225 --log-failed`. Локально (Swift новее) собирается. После этих ошибок могут вылезти следующие — например `NSControl.ControlSize.extraLarge` в `SettingsView.swift` (символ есть только в SDK macOS 26, `#available` от отсутствия символа не спасает) — **не подтверждено**.

### P1

Подтверждённых нет.

### Не подтверждено (наблюдалось, причина не найдена)

- **Настройки открываются не на том разделе.** Дважды при первом открытии окна: `--settings sources` открыл «Основные», `--settings character` открыл «Агенты». Код ставит раздел до создания окна (`AppDelegate.showSettings`). Подозрение — восстановление выбора списка `NavigationSplitView`. Если так же ведёт себя кнопка «Подключить» в Пульте (`showSettings(.sources, anchor: "Лимиты")`), это P1.
- **Поле поиска в настройках может не получать клики.** Оно стоит в зоне невидимой системной панели (0–65 pt сверху). Синтетический клик проверить не удалось. Нужна ручная проверка.
