# Улучшения существующих сценариев · 2026-11-10

Разрешены владельцем: развитие двадцати предложенных сценариев без новых страниц и изменения сетки Пульта. Изменения идут отдельными рабочими коммитами с push в main; ориентир 50–100, без пустых коммитов и искусственного дробления.

## Библиотека

- [ ] Связь с переименованными / перемещёнными файлами, совместимость прежнего хранилища.
- [ ] Обновление превью изменённых файлов и признаки недоступности в прежних плитках.
- [ ] Quick Look по пробелу, клавиатурная навигация и расширение выделения.
- [ ] Отмена и повтор удаления ссылок.
- [ ] Контекстные действия: открыть, показать в Finder, скопировать путь, найти файл.

## Переводчик

- [ ] Пара языков между запусками и повтор после загрузки языков.
- [ ] Сохранение структуры, ссылок и кода в переводе.
- [ ] Отменяемая замена через обычное редактирование целевого приложения.
- [ ] Обратный перевод из контекстного меню с возвратом к оригиналу.

## Докладчик и диктовка

- [ ] Черновик между запусками, сохранение места и возобновление.
- [ ] Голосовое следование при пропусках и самопоправках, адаптация к темпу.
- [ ] Явное голосовое исправление последней диктовки по отдельной клавише.

## Агенты и система

- [ ] Объединение близких завершений без заглушения ожиданий и ошибок.
- [ ] Переход к конкретной сессии там, где источник имеет проверяемый адрес.
- [ ] Обновление лимитов после возвращения сети.
- [ ] Надёжная память позиции по мониторам: сдвиги уже сохраняются, проверить стабильность идентификатора после переподключения.

## Проверка

Завершение: тесты логики, release, установка, нативные снимки четырёх разделов и доступная интерактивная проверка. Непроверенные микрофон, физический трекпад, внешние редакторы и второй монитор отмечаются отдельно. Локальные тексты и ссылки не входят в git.
