# Установка Agent Pulse с помощью своего агента

Скопируйте запрос ниже агенту, у которого есть терминал на **вашем Mac**. Обычный чат без доступа к компьютеру сможет только объяснить шаги. Пароли, вход в аккаунты и системные разрешения остаются за владельцем Mac.

## Готовый запрос

```text
Установи и запусти Agent Pulse на моём Mac из публичного репозитория:
https://github.com/egorovdnikita/agent-pulse

Нужна установка работающего приложения, а не разработка. Используй актуальную
инструкцию docs/setup.md из репозитория. Если клона ещё нет, сначала проверь Mac
и инструменты, затем клонируй через HTTPS в ~/Projects/agent-pulse. Если папка уже
есть — проверь remote и git status; мои изменения не удаляй и не сбрасывай.

1. Проверь sw_vers -productVersion, uname -m, xcode-select -p,
   xcrun swift --version и xcrun --sdk macosx --show-sdk-version.
   Текущий штатный установщик рассчитан на Apple Silicon / arm64.
   Нужны инструменты Xcode 26+ со Swift 6.2+ и SDK macOS 26+.
   Проверенная среда — macOS 26 на Apple Silicon; на неподдерживаемой среде
   объясни конкретное ограничение, а не подменяй библиотеки и требования.
2. Если инструментов нет, запусти xcode-select --install и дай мне закончить
   системную установку. После неё повтори проверки. Полный Xcode и Homebrew
   не устанавливай, если подходят Command Line Tools. Не меняй мой активный
   Xcode или toolchain без объяснения необходимости.
3. Прочитай docs/setup.md. Выполни из корня scripts/install.sh без sudo.
   Дождись завершения и запиши фактический путь установленной .app.
   Автозапуск не включай без моей просьбы; для него существует --login.
4. Проверь установленное приложение: процесс AgentPulse запущен,
   есть значок в строке меню, Control+Option+X раскрывает Пульт, Esc закрывает,
   доступны настройки и Библиотека. Иконки в Dock быть не должно.
   Если умеешь управлять интерфейсом — проверь глазами; иначе попроси меня
   выполнить конкретную короткую проверку и явно отдели её от проверки сборки.
5. Выполни scripts/test.sh. При необходимости покажи демонстрацию через
   scripts/demo-events.sh, но не выдавай отправку событий за визуальную проверку.
6. Базовую установку заверши со стандартным маскотом. Платный Agent Pals,
   чужие конфиги, шрифты автора, аккаунты, .env и токены не нужны.
7. После базовой установки уточни, какие подключения мне нужны:
   Claude Code/Codex, лимиты, браузер/Figma, диктовка, перевод, одиночный Control.
   Подключай только выбранное через настройки Pulse. Не перезаписывай целиком
   настройки CLI. Не скачивай платные материалы и не авторизуй сервисы за меня.
   Системные разрешения, пароль администратора и соглашения передавай мне.
8. При ошибке сохрани команду и полный вывод, установи причину по инструкции.
   Не отключай Gatekeeper/TLS, не убирай SHA-256, не делай reset --hard
   и не удаляй мои данные. Не коммить и не публикуй ничего ради локальной
   установки. Старые HANDOFF и журналы разработки — история проекта,
   они не являются задачами на доработку в рамках этой установки.

В конце сообщи:
- версии macOS, архитектуры, Swift и SDK, коммит установленной версии;
- куда установлено приложение и запущен ли единственный его экземпляр;
- что проверено глазами, что только тестами/командами, что осталось проверить;
- какие источники/разрешения включены и какое конкретное действие нужно от меня.
Не называй установку завершённой, если сборка упала или приложение не запущено.
```

## Что должно получиться

Работающий стандартный маскот и Пульт без сторонних аккаунтов. Подключённые CLI показывают свою активность только после отдельной настройки. Пустые лимиты до подключения, отсутствие Agent Pals и выключенная диктовка — ожидаемые исходные состояния.

Если агенту нужен только краткий ориентир: [требования и установка](setup.md#1-проверить-mac-и-инструменты), [проверка запуска](setup.md#4-убедиться-что-приложение-работает), [разбор ошибок](setup.md#9-если-не-заработало).
