# Установка Agent Pulse на другой Mac

Эта инструкция подходит для самостоятельной установки и для агента, который работает на вашем Mac. Готовый запрос агенту — в [install-for-agent.md](install-for-agent.md). Базовый маскот и Пульт работают без платного пака, Claude Code, Codex, Orca и ключей API.

Сейчас приложение устанавливается **сборкой из исходников**. Готового нотарифицированного DMG и автоматического обновления пока нет.

## 1. Проверить Mac и инструменты

| Что | Требование |
|---|---|
| Процессор | Apple Silicon, то есть Mac с чипом серии M; сборка в нативном режиме `arm64` |
| macOS | Для повторения проверенной установки рекомендуем macOS 26 или новее |
| Инструменты | Command Line Tools для Xcode 26 или новее: Swift 6.2+ и SDK macOS 26+; полный Xcode необязателен |
| Интернет | Нужен для исходников, Lottie и рантайма диктовки; модели и языки скачиваются отдельно при включении соответствующих функций |
| Платные материалы и аккаунты | Для базового запуска не нужны |

В проекте задан минимальный deployment target macOS 14. Это **не означает**, что текущие исходники можно собрать инструментами macOS 14: код перевода требует SDK macOS 26. Запуск на macOS 14/15 отдельно не подтверждён. Текущий установщик скачивает библиотеки диктовки только для `arm64`; установку на Intel и сборку под Rosetta эта инструкция не обещает.

Откройте «Терминал» и выполните:

```bash
sw_vers -productVersion
uname -m
xcode-select -p
xcrun swift --version
xcrun --sdk macosx --show-sdk-version
```

Ожидается `arm64`, Swift не ниже 6.2 и SDK не ниже 26. На Apple Silicon вывод `x86_64` означает запуск терминала под Rosetta: сначала откройте нативный терминал. На Intel на этом шаге остановитесь — установка текущих библиотек не даст рабочую русскую диктовку.

### Если инструменты ещё не установлены

```bash
xcode-select --install
```

Дождитесь установки в системном диалоге; после её окончания повторите проверки выше. Это отдельный шаг, а не мгновенная команда. Инструкции Apple: [установка Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools), [совместимость версий Xcode и SDK](https://developer.apple.com/xcode/system-requirements).

Если инструменты уже стоят, но Swift или SDK старые, обновите Command Line Tools через «Системные настройки → Основные → Обновление ПО» либо установите совместимый пакет с [сайта Apple Developer](https://developer.apple.com/download/all/). Само сообщение «инструменты уже установлены» не подтверждает нужную версию.

Если установлен полный Xcode, откройте его один раз и завершите первоначальную настройку. При неверно выбранном пути инструментов выберите нужный Xcode в его настройках Locations → Command Line Tools либо переключите путь:

```bash
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
```

Эта команда нужна только для установленного по указанному пути Xcode; для обычных Command Line Tools она не нужна. Пароль администратора и системные соглашения владелец подтверждает сам.

Homebrew, Node.js, npm, Python из Homebrew, CocoaPods и аккаунт платного Apple Developer для базовой сборки не требуются. Git, компиляторы и используемые системные утилиты приходят вместе с инструментами Apple.

## 2. Скачать исходники

```bash
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/egorovdnikita/agent-pulse.git
cd agent-pulse
```

Репозиторий публичный: вход в GitHub и настройка SSH не нужны. Если папка `agent-pulse` уже существует, не удаляйте её и не клонируйте поверх. Перейдите в неё, проверьте `git remote -v` и `git status --short`; обновление существующей копии описано ниже.

Все следующие команды со скриптами выполняются **из корня репозитория**, где лежат `Package.swift` и папка `scripts`.

## 3. Собрать, установить и запустить

```bash
scripts/install.sh
```

Скрипт сам:

1. Собирает release через Swift Package Manager и скачивает закреплённую в `Package.resolved` версию Lottie.
2. Скачивает рантайм sherpa-onnx/ONNX Runtime; архив проверяется закреплённой SHA-256. Модель распознавания речи на этом шаге не скачивается.
3. Создаёт `.app`, добавляет ресурсы и локально подписывает приложение. Если своего сертификата нет, используется ad-hoc подпись.
4. Завершает старый экземпляр Agent Pulse, устанавливает новый и запускает его.
5. Убирает временную копию `.app` из `build`, чтобы не было дубля в Launchpad.

Первая сборка может занять несколько минут. Дождитесь конца: последняя строка показывает установленный путь. Обычно это `/Applications/Agent Pulse.app`; если запись в `/Applications` недоступна — `~/Applications/Agent Pulse.app`. Запускать весь скрипт через `sudo` не нужно.

Чтобы сразу включить запуск при входе:

```bash
scripts/install.sh --login
```

Или после установки включите «Настройки → Основные → Запускать при входе». Для повторного запуска используйте Finder либо фактический путь из вывода установщика, например:

```bash
open "/Applications/Agent Pulse.app"
```

Устанавливать Agent Pals, создавать `.env`, вводить токен или вручную копировать библиотеки не требуется. Шрифты Inter/Geist и обычные иконки есть в репозитории; локальный необязательный display-шрифт для запуска не нужен.

## 4. Убедиться, что приложение работает

Agent Pulse — приложение строки меню: **обычной иконки в Dock у него нет**. В строке меню появляется его значок. Маскот находится в углу экрана, капсула Пульта — в противоположном углу у Dock.

1. Выйдите из полноэкранного режима другого приложения и посмотрите на обычный рабочий стол: в полном экране маскот может быть скрыт намеренно.
2. Нажмите **Control + Option + X** (`⌃⌥X`) или кликните капсулу. Должна раскрыться панель с разделами «Нейросети», «Докладчик», «Библиотека», «Переводчик»; доступность перевода зависит от macOS.
3. Нажмите `Esc`: Пульт должен свернуться.
4. Через значок в строке меню или правый клик по маскоту откройте «Настройки…».
5. В раскрытом Пульте откройте «Библиотека», добавьте любой свой тестовый файл и уберите его с полки. Это ссылки: удаление с полки не удаляет оригинал файла.

В пустых лимитах прочерк — нормальное состояние, пока не подключены источники; это не ошибка установки. Маскот в покое может скрываться по настройкам: в меню есть «Показывать маскота».

Проверка процесса из терминала:

```bash
pgrep -x AgentPulse
```

Для демонстрации событий без настоящего агента:

```bash
scripts/demo-events.sh
```

Скрипт отправляет вымышленные события работающему приложению: маскот проходит работу, ожидание разрешения и завершение. Он не меняет ваши файлы и не устанавливает хуки. Посмотрите результат на экране; успешная отправка сама по себе не доказывает, что маскот виден.

Для проверки кода:

```bash
scripts/test.sh
```

Установка и тесты — разные проверки: зелёные тесты не заменяют открытие установленного приложения и Пульта.

## 5. Разрешения: включать для нужных функций

| Функция | Что понадобится |
|---|---|
| Маскот, Пульт, Библиотека, `⌃⌥X` | Универсальный доступ, запись экрана и мониторинг ввода не нужны |
| Системные уведомления | Разрешить уведомления, если хотите получать их, пока маскот скрыт |
| Одиночный Shift | Универсальный доступ для глобальных событий модификаторов; текст клавиш не читается |
| Диктовка и следование Докладчика за голосом | Микрофон; для системного распознавания также разрешение распознавания речи |
| Вставка в другое приложение и перевод выделения | Универсальный доступ, включается отдельно в нужном модуле |
| Слежение за чатом Claude desktop | Универсальный доступ и отдельное включение в «Агенты» |
| Автоматическое добавление снимков экрана на полку | Доступ к папке снимков, если macOS его запросит |

Разрешения выдаются владельцем в системных диалогах. Не нужно включать всё для базового запуска. Подробности обработки данных — в [privacy.md](privacy.md).

### Открытие Пульта по Shift

В «Настройки → Модули → Клавиша раскрытия» выберите «Shift — короткое нажатие». Одиночное нажатие не дольше 0,45 с открывает или закрывает Пульт **при отпускании**. Shift при наборе, клике/прокрутке мышью и в сочетании с другим модификатором не должен раскрывать панель.

Если появилась кнопка «Разрешить Shift в Универсальном доступе», нажмите её, затем включите Agent Pulse в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Разрешение подхватывается без перезапуска. Проверьте физической клавишей: короткий Shift открывает Пульт, `Shift + буква` не открывает. Прежние сочетания с `⌃⌥` остаются в списке настроек.

## 6. Подключить только используемые источники

Ни один из этих пунктов не обязателен для маскота и Пульта. Установка Pulse не устанавливает сами Claude Code, Codex или Orca и не авторизует их за вас.

### Claude Code и события Codex

В Pulse откройте «Настройки → Агенты», строку Claude Code и нажмите «Подключить». Приложение добавляет свои хуки с резервными копиями; чужие хуки сохраняются. В том числе подключаются поддерживаемые хуки Codex, если его конфигурация есть на этом Mac.

Запустите **новую** сессию установленного и авторизованного CLI и выполните небольшой запрос. Проверьте изменение состояния маскота; существующая сессия могла загрузить старую конфигурацию до установки хуков. Не подменяйте целиком `~/.claude/settings.json` или `~/.codex/hooks.json` чужими примерами.

### Лимиты Claude и Codex

В «Настройки → Агенты → Лимиты» подключите Claude отдельной кнопкой: это обёртка statusline, а не те же хуки событий. Если Claude Code на этом аккаунте отдаёт лимиты, они появятся после ответа в новой сессии. Доступность зависит от аккаунта и данных CLI; отсутствие лимитов не означает, что маскот сломан.

Для лимитов Codex нужен установленный и авторизованный `codex`: Pulse вызывает его `app-server`. Если он не найден, задайте путь к исполняемому файлу в строке «Где лежит Codex». При нескольких аккаунтах выберите свой профиль в том же разделе. Не копируйте чужие аккаунты, токены и пути с другого Mac.

### Orca и Claude Cowork

В «Настройки → Агенты» проверьте соответствующие строки и переключатели. Pulse ищет локальные данные этих приложений; если их нет, статус «не найден» ожидаем. Устанавливать Orca или Cowork только ради Pulse не нужно.

### Claude в Chrome и Figma Make

1. В «Настройки → Агенты → Claude в браузере» нажмите «Подключить», затем «Показать расширение».
2. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное».
3. Выберите папку `~/Library/Application Support/AgentPulse/ChromeExtension`.
4. Откройте поддерживаемый сайт и проверьте события при реальной работе. Расширение устанавливается в нужный профиль Chrome вручную.

### Figma

В «Настройки → Агенты → Figma» нажмите «Показать плагин». В Figma desktop: Plugins → Development → Import plugin from manifest… → выберите `manifest.json` из открывшейся папки. Запускайте плагин в нужном файле. Это отдельное подключение, не обязательная зависимость сборки.

## 7. Дополнительные модули и облик

### Диктовка

В «Настройки → Модули → Диктовка» включите модуль и выберите язык. Для русского нажмите загрузку модели и дождитесь статуса «Скачана»; модель GigaAM загружается отдельно, с проверкой контрольной суммы. Разрешите микрофон, затем удерживайте `Control + Option + D`, произнесите фразу и отпустите. Автовставка в чужое поле настраивается отдельно через Универсальный доступ. Сначала проверяйте на своём тестовом тексте.

### Докладчик и перевод

Докладчик без голоса можно проверить обычным текстом в Пульте. «За голосом» включает отдельный доступ к микрофону/распознаванию.

Переводчик работает на macOS 26+. В «Настройки → Модули → Перевод» нажмите «Языки» и дождитесь загрузки системных языков. После этого проверьте перевод небольшой фразы. Модель русской диктовки и языки перевода — разные загрузки.

### Agent Pals — необязательно

Стандартный светящийся маскот работает сразу. Боты из демонстрационного ролика — платный пак Agent Pals; он не входит в репозиторий и автоматически не скачивается.

Если у вас есть свой архив пака, сначала выйдите из Pulse через «Выйти из Agent Pulse», затем из корня репозитория выполните:

```bash
scripts/install-agent-pals.sh "/полный/путь/к/вашему-паку.zip" Circle
```

Откройте установленное приложение снова. Выбор облика находится в «Настройки → Основные → Облик». Для этой необязательной команды используется системный `/usr/bin/python3` из инструментов Apple. Копировать конфигурацию или платные файлы автора проекта не нужно.

## 8. Обновление

В вашей папке репозитория:

```bash
git status --short
git pull --ff-only
scripts/install.sh
```

Если первая команда показывает ваши изменения или `pull` сообщает о конфликте, сначала разберите их; не используйте `reset --hard` и не удаляйте папку ради обновления. `install.sh` сам заменяет приложение, настройки остаются в Application Support. При смене расположения приложения можно повторно выполнить установку с `--login` для перерегистрации запуска при входе.

Локальная ad-hoc подпись может меняться после сборки. Если после обновления перестали работать Shift или вставка, проверьте разрешение Agent Pulse в Универсальном доступе; при необходимости удалите старую запись и добавьте установленную `.app` заново. Постоянный локальный сертификат поддерживается через `AGENT_PULSE_SIGN_IDENTITY`, но для первой установки не обязателен.

## 9. Если не заработало

| Симптом | Что проверить |
|---|---|
| `xcrun` / `swift` не найдены | Закончилась ли установка Command Line Tools; работают ли команды из шага 1 |
| Нет `TranslationSession`, ошибки SDK или Swift | Активен ли SDK 26+ и совместимый Swift из того же набора инструментов; одного Swift 6.0 недостаточно |
| `toolchain` / `SDK not supported by compiler` | Проверьте `xcode-select -p`, `xcrun swift --version`, версию SDK; не смешивайте старый пользовательский toolchain и новый SDK |
| Не скачались Lottie или рантайм | Доступ к GitHub и адресам загрузок; повторите команду после восстановления сети. Не убирайте проверку SHA-256 и не отключайте TLS |
| Ошибка контрольной суммы | Не использовать скачанный файл и не менять ожидаемый SHA ради прохождения; сохраните полный вывод и версию скрипта для разбора |
| Приложение «не открылось», иконки нет в Dock | Это menu bar app; проверьте строку меню, `pgrep -x AgentPulse`, обычный рабочий стол и `⌃⌥X` |
| Приложение установлено не туда | Последняя строка `install.sh` показывает фактический путь; возможен `~/Applications` |
| Маскот не виден | Не полный ли экран; включено ли «Показывать маскота»; не скрывается ли он в покое |
| Пульт не открывается | В «Модули» включён «Показывать Пульт»; комбинация могла быть занята другим приложением — выберите другую букву |
| Shift не открывает Пульт | Выбран ли Shift, есть ли Универсальный доступ, нажимаете ли коротко и отдельно; после пересборки проверьте запись разрешения |
| Лимиты пустые | Подключены ли именно лимиты; авторизован ли нужный CLI; есть ли новые данные аккаунта |
| Не работает русская диктовка | Нативный `arm64`, модель «Скачана», разрешён микрофон; не путайте наличие рантайма со скачанной моделью |
| macOS блокирует запуск | Запишите точное сообщение и проверьте источник/сборку; готовой нотарифицированной дистрибуции пока нет. Не отключайте Gatekeeper целиком |

Для отчёта приложите macOS, архитектуру, версии Swift/SDK, коммит (`git rev-parse --short HEAD`), команду и полный вывод ошибки. Перед отправкой уберите токены, личные тексты и контакты. Сборочный лог можно сохранить так:

```bash
scripts/bundle.sh release > build-install.log 2>&1
```

Проверка установленной подписи — с фактическим путём приложения:

```bash
codesign --verify --deep --strict "/Applications/Agent Pulse.app"
```

Скрипт `bundle.sh` только собирает приложение в `build`; для установки и перезапуска после исправления используйте `install.sh`.

## 10. Удаление

1. В «Настройки → Агенты» отключите подключённые хуки Claude Code и лимиты Claude. Используйте кнопки приложения: чужие настройки сохраняются, рядом остаются резервные копии.
2. Если использовали расширение Chrome, отключите его в Pulse и удалите из `chrome://extensions`.
3. В «Основные» выключите запуск при входе, затем выберите «Выйти из Agent Pulse».
4. Перетащите установленную `.app` в Корзину. Исходники в `~/Projects/agent-pulse` удаляются отдельно, если больше не нужны.
5. Необязательный сброс данных: `~/Library/Application Support/AgentPulse` — память, настройки, облики и скачанная модель. Удаляйте эту папку только если хотите потерять локальные данные.

Если приложение удалили, не сняв хуки, `pulse-hook` рассчитан на недоступность приложения; всё же штатное отключение перед удалением предпочтительнее.

## Что проверено

Проверка 2026-11-09: новый публичный клон коммита `3b81ace`, без локальной `.build`, платного пака и display-шрифта автора. `scripts/bundle.sh release` собрал `.app` с ad-hoc подписью; `codesign --verify --deep --strict` прошёл, исполняемый файл и скачанный рантайм — `arm64`. `scripts/test.sh`: 346 тестов в 81 наборе прошли. Это проверка нового клона на существующей системе, а не переустановленной macOS; установка инструментов Apple с нуля, Intel и запуск на macOS 14/15 отдельно не проверялись. Установленный экземпляр приложения и его настройки при этой дополнительной сборке не заменялись.
