# Промо Pulse для профиля GitHub

Офлайн-отрисовка настоящих компонентов SwiftUI/AppKit и персонажа Agent Pals / Circle на виртуальных часах. Личные лимиты и недавние тексты не читаются. Перевод задан сценарием, сетевых запросов и записи экрана нет.

Результат: зацикленный WebP, 1600 × 880, 60 кадров/с, 52,5 секунды, сжатие без потерь (параметр качества 92). Фон GitHub Dark `#0d1117`, обводка `#3d444d`, скругление 20 pt. Курсора нет, клики показаны кольцами. Клипы Lottie отрисовываются движком mainThread; установленный платный пак нужен только при сборке исходных кадров и в git не входит.

```sh
python3 -m venv /tmp/pulse-promo-env
/tmp/pulse-promo-env/bin/pip install pillow imageio-ffmpeg
scripts/bundle.sh release
/tmp/pulse-promo-env/bin/python scripts/promo/promo.py /tmp/pulse-promo \
  --app "$PWD/build/Agent Pulse.app/Contents/MacOS/AgentPulse"
```

Для реального Dock передать `--dock /путь/dock.png --dock-screen-width 1680`: PNG только окна Dock, прозрачный, обрезанный по альфа-каналу, Retina 2x; ширина его экрана задаётся в pt. `--dock-cut 1794:2040` исключает лишний диапазон исходника, например секцию второго Chrome перед корзиной; остальные пиксели и значки сохраняются. Капсула и маскот выравниваются по середине видимой плашки Dock, а для облачка проверяется свободный зазор. Захват всего рабочего стола не использовать. Снимок Dock остаётся за пределами репозитория приложения.

`--only-assets` обновляет страницы без кадров маскота и монтажа; `--only-compose` использует уже отрисованные исходники. `--keys-only --only-compose` быстро рисует контрольные кадры без кодирования. `keys.json` — список секунд для контрольных PNG.

Координаты кликов не задаются вручную: маркеры `promoTarget` измеряют настоящие кнопки после раскладки AppKit/SwiftUI и сохраняют соседние `*.targets.json`. Сценарий требует нужный маркер и хранит точку вместе с прямоугольником кнопки в `clicks.json`; кольцо привязано к этой точке, а не к траектории скрытого курсора. Маркеры появляются только в офлайн-отрисовке.

Библиотека рисуется отдельной двухсекундной петлёй Lottie. Докладчик прокручивается на виртуальных часах: запуск, пауза, продолжение и остановка, без таймера, показа окна и сохранения текста в «Недавних». Перед монтажом проверяются наличие всех кадров, движение обеих анимаций, неподвижность текста на паузе и центры кликов; результат — `verification.json`.

Сценарий: состояния агента → пустые и заполненные лимиты → пустая Библиотека, перетаскивание PDF, добавление файлов, выделение и удаление → ускоренный набор текста Докладчика, скорость, запуск верхней панели, пауза и остановка → набор текста Переводчика, ожидание результата, копирование и очистка.


## Эффекты интерфейса

Проценты в шкалах и капсуле отсчитываются от нуля; дуги заполняются с тем же прогрессом. Цифры проявляются с небольшим подъёмом и расфокусировкой. Кадры строятся настоящими `LimitGauge` и `LimitSide`, параметры промо передаются через environment и не меняют обычный интерфейс.

Файлы используют измеренные прямоугольники настоящих плиток: перетаскивание продолжается посадкой в первую ячейку, добавление — последовательным появлением и перестановкой, удаление — уменьшением, подъёмом и затуханием. Персонаж и подсказка пустой Библиотеки появляются после удаления файлов.

Верхняя панель — только системная строка меню macOS. `--menu-bar /путь/фрагмент.png --menu-bar-height 60` принимает отдельный фрагмент 2x и отрезает всё ниже 60 px; личные страницы и вкладки не снимаются. Картинка остаётся вне репозитория приложения. Высота строки рассчитывается по ширине рабочего стола, Докладчик ставится на 6 pt ниже её нижнего края; его подсветка плавно переходит между словами и замирает на паузе.

Камера Пульта центрируется относительно панели 640 pt: в виде шириной 720 pt остаётся ровно по 40 pt с обеих сторон. То же положение применяется при обоих раскрытиях и на всех страницах.
