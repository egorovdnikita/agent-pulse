# Промо Pulse для профиля GitHub

Офлайн-отрисовка настоящих компонентов SwiftUI/AppKit и персонажа Agent Pals / Circle на виртуальных часах. Личные лимиты и недавние тексты не читаются. Перевод задан сценарием, сетевых запросов и записи экрана нет.

Результат: зацикленный WebP, 1600 × 880, 60 кадров/с, 52 секунды, сжатие без потерь (параметр качества 92). Фон GitHub Dark `#0d1117`, обводка `#3d444d`, скругление 20 pt. Курсора нет, клики показаны кольцами. Клипы Lottie отрисовываются движком mainThread; установленный платный пак нужен только при сборке исходных кадров и в git не входит.

```sh
python3 -m venv /tmp/pulse-promo-env
/tmp/pulse-promo-env/bin/pip install pillow imageio-ffmpeg
scripts/bundle.sh release
/tmp/pulse-promo-env/bin/python scripts/promo/promo.py /tmp/pulse-promo \
  --app "$PWD/build/Agent Pulse.app/Contents/MacOS/AgentPulse"
```

Для реального Dock передать `--dock /путь/dock.png --dock-screen-width 1680`: PNG только окна Dock, прозрачный, обрезанный по альфа-каналу, Retina 2x; ширина его экрана задаётся в pt. Захват всего рабочего стола не использовать. Снимок Dock остаётся за пределами репозитория приложения.

`--only-assets` обновляет страницы без кадров маскота и монтажа; `--only-compose` использует уже отрисованные исходники. `keys.json` в выходной папке — список секунд для контрольных PNG. Измеренные центры вкладок можно задать в `tabs.json`; значения по умолчанию соответствуют текущему Пульту.

Сценарий: состояния агента → пустые и заполненные лимиты → пустая Библиотека, перетаскивание PDF, добавление файлов, выделение и удаление → набор текста Докладчика, скорость и очистка → набор текста Переводчика, ожидание результата, копирование и очистка.
